## 🚀 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置环境
cp .env.example .env

# 3. 初始化数据库
python -m src.database.migrations

# 4. 启动服务
python -m src.api.main

# 5. 访问API文档
# http://localhost:8000/docs
```
